# 顶级机场 (Imperial Network) · dijichang.blog

**设计框架**：IMPERIAL ONE MAX · 皇家至尊旗舰
**美术主题**：白金皇家商务科技（Platinum Royal Business Tech）
**核心宣传语**：真正的品质，不止于速度。（True Quality Goes Beyond Speed.）
**原创角色**：AUREVIA · 奥蕾薇娅（品质顾问） & ORION · 铂金智核（智能助手）

## 技术栈
- Astro 5 + TypeScript + Preact
- 统一 JSON 数据模型（`data/`）
- 纯原生独立原创 SVG 视觉资产与 GPU 友好型 CSS 动效（支持 `prefers-reduced-motion` 与手动关闭）

## 本地开发与构建
```bash
npm install
npm run dev
npm run build
```
